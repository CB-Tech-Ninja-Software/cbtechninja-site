SweepNinja working name

A lean desktop utility that shows where your disk space went and lets you reclaim it safely: no bundled extras, nothing deleted without a preview and a way back.

Status: in development. The final product name has not been chosen, and there is no public release yet.

The problem

Developer machines silently fill with build folders, caches and duplicate files, and most cleaners are either bloated or too willing to delete things you needed.

What it does

Treemap of disk use

See at a glance which folders take the space.

Developer artifacts

Finds regenerable build output such as node_modules, target, .dart_tool and DerivedData and offers safe deletion.

Duplicate finder

Progressive hashing (size, then the start and end of each file, then a full BLAKE3 hash) with a hash cache so rescans are quick.

Large and old files

Surfaces big files that have not been touched in months.

System and browser caches

Clears package-manager, browser and temporary caches.

Undo and audit log

Deletes go to the Trash or Recycle Bin by default, every action is written to an audit log, and cleaned items can be restored.

Safety first

Every deletion passes a hard-coded never-touch list (system folders, credentials, active git checkouts, ML model caches), a dry-run summary, the Trash engine and the audit logger. One exception is stated plainly: if the Recycle Bin is turned off on a volume, or a file is too large for it, the file is removed permanently.

How it is built

A Rust workspace of small crates (scanner, dedup, trash, engine and app) targeting macOS 12+ and Windows 10+, with a tested core and a Windows installer script.
