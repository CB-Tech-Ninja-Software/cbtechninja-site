SyncNinja

SyncNinja keeps folders on a portable SSD in sync with whichever machine it is plugged into. Plug in the drive and it starts; pull it out and your files are safely on both sides.

Status: in development. SyncNinja is not released and has no store listing. This page describes what the code does today.

The problem

Working on two or three computers with one portable drive usually means dragging folders by hand, overwriting the wrong copy, and discovering a deleted file a week later.

What it does

Two sync modes, per folder pair

Merge is two-way sync built on rclone bisync. Mirror is one-way, with the source machine as the authority.

Safe deletes

Mirror mode moves deleted files into a trash folder on the drive and prunes it after 30 days. Deletes are previewed first and bulk deletes need confirmation.

Conflict scanning

Conflicting copies are detected and reported instead of silently overwritten.

Optional encryption

A drive can use rclone crypt. The password is supplied at run time and never written to the config file.

Plug-in detection

Drives are recognised by a marker file. On macOS a LaunchAgent starts the app when a volume mounts; on Windows it uses a scheduled task.

Tray and background mode

A tray icon shows live progress and speed, and sends a notification when a sync completes.

Git-aware

.git folders are always excluded unless a pair explicitly opts in to including repositories.

How it is built

An Electron desktop app for Windows (64-bit) and macOS 13 or newer, with a Node.js command-line engine underneath and rclone doing the transfers. The vault password can be saved in the operating system's credential store.
