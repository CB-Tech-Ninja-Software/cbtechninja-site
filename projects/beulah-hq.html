Beulah HQ

A desktop app that runs a team of AI coding agents on your own computer, each one a real terminal process with a name, a memory and a mailbox.

Status: internal tool. We use Beulah HQ internally to build and maintain our own software. It is not sold or distributed. A native Rust rewrite (working name AIOai) is in early development.

What it does

Real agents, real terminals

Wraps command-line agent tools such as Claude Code, Codex and Gemini CLI, each running as its own process in its own working folder.

Memory and mailboxes

Agents keep persistent notes and message each other through a file-based mailbox, coordinated by an orchestrator agent that escalates spend and risky actions to the human.

Office-floor view

A 2D office visualisation shows who is working, waiting or blocked.

Beulah Remote

A relay status and control panel for reaching the app from elsewhere, with interface binding and restart controls.

Local first

State lives in a local git repository with a single committer, so there are no lock conflicts and everything is auditable.

How it is built

Electron, React, TypeScript, Pixi.js for the office floor, xterm.js and node-pty for terminals, and SQLite for durable state.
