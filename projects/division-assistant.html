Division Assistant

A private analytics desktop app that gives a homebuilding division leader one place for P&L, lot inventory, backlog and land pipeline, alongside public housing-market data.

Client work, described in general terms. The real application holds a company's confidential financial data, so this page names no client, shows no real figures and uses no screenshots of live data. The illustration below is invented.

What it does

Community and P&L views

Performance by community, with the metrics a division president actually reads.

Lot and spec inventory

Lot counts and spec-home construction stages in one view.

Backlog and margins

Sales backlog with margin analysis.

Land deal pipeline

Track land deals through their stages.

Public housing-market data

Pulls public macro series (FRED, Census building permits, Freddie Mac mortgage rates, BLS employment) over HTTPS.

Report import with OCR

Scanned PDFs and photos are read with OCR, split into report types, parsed into rows and reviewed before they are saved.

How it is built

A single-user, local-first desktop app: Electron with a hardened renderer, React and TypeScript, and a SQLite database encrypted with SQLCipher so the data is protected at rest. Money is stored as integer cents throughout. The project ships with synthetic seed data and an automated test suite for development.
